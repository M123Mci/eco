## 构建和发布

使用 Java 25，依赖 JAR 位于 `D:/Minecraft/PluginLibs/Jars`，本地 Maven 位于同级 `Maven`。可用 `-PexternalPluginLibDir=...` 和 `-PlocalPluginRepoDir=...` 指定其他目录。

```bat
gradlew.bat :eco-api:compileJava :eco-core:core-nms:v26_2:compileKotlin
gradlew.bat clean shadowJar
gradlew.bat :eco-core:core-nms:v26_2:checkNmsLinkage
gradlew.bat distribute publishPluginPublicationToLocalPluginsRepository :eco-api:publishApiPublicationToLocalPluginsRepository
```

API 坐标保留 `com.willfp:eco:2026.36-mr.1`；完整插件使用 `com.willfp:eco-plugin:2026.36-mr.1`，避免同一坐标的 API 与完整插件互相覆盖。构建不自动部署测试服，不向官方仓库发布。
